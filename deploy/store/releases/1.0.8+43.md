## iOS signing: Associated Domains had to be enabled

The App ID `com.laawoldigital.app` had only Push and In-App Purchase, so the
first archive failed ("profile doesn't include the Associated Domains
capability") and Xcode had no Apple account to fix it. Associated Domains was
enabled through the App Store Connect API (`bundleIdCapabilities`), and the
archive/export ran with `-allowProvisioningUpdates` plus the ASC API key
(`-authenticationKeyPath/-ID/-IssuerID`) so Xcode fetched a fresh profile
without a signed-in account.

## Play caps release notes at 500 characters

Not 4000. A longer note uploads and sets the track fine, then the edit
`:commit` fails with **403 PERMISSION_DENIED** — "notes in language en-US with
length 604, which is too long (max: 500)". The status code says permission; the
cause is length. `notes/1.0.5.json` is written to fit Play, and Apple accepts
the same text.

Note the failed commit discards the whole edit, uploaded bundle included — the
bundle does **not** persist the way it does after a transient tracks-PUT 503.

## What it carries

Three pull requests since 1.0.5+40:

- **#98** brought the app level with the console on parking and the lot ledger.
  Six callables the web had been calling for fifteen pull requests were never
  called from the app: `billParkingThroughToday`,
  `recordParkingPaymentReceived`, `closeParkingStay`, `upsertLotActivityType`,
  `deleteLotActivityType`, `setExpenseProofThreshold`. It also fixed a console
  bug — a Copy button offered for a payment link the lot had already cancelled
  — which is already live on the web.
- The customer **Home** rebuilt around a "Send something home" hero.

No functions changed, so nothing was deployed to Cloud Run for this release.

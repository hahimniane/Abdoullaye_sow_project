Conditions des messages texte

Comment Laawol et les entreprises d’expédition qui l’utilisent vous envoient des messages texte au sujet d’un colis, comment vous les acceptez et comment les arrêter.

Entrée en vigueur : 23 novembre 2026

En bref

Nous vous écrivons par texto uniquement au sujet d’un colis que vous avez déposé, et seulement si vous le demandez.

  • Un message par demande. Aucune publicité.
  • Répondez STOP pour arrêter, HELP pour de l’aide.
  • Nous ne partageons jamais votre numéro ni votre accord à des fins de marketing.
Nous contacter

1. Qui envoie ces messages

Laawol Digital LLC (« Laawol ») exploite la plateforme Laawol. Les entreprises d’expédition qui utilisent Laawol pour enregistrer des colis envoyés des États-Unis vers l’Afrique de l’Ouest envoient les messages sur les colis depuis le numéro gratuit de Laawol, +1 (866) 346-6017. Chaque message commence par le nom de l’entreprise où vous avez déposé votre colis.

2. Comment vous acceptez de recevoir un texto

Vous acceptez en personne, au comptoir. Quand vous déposez un colis, l’employé vous demande votre numéro de mobile et vous pose la question :

« Nous pouvons vous envoyer le reçu de votre colis par message texte à ce numéro : un message chaque fois que vous demandez un reçu. Des frais de messages et de données peuvent s’appliquer. Répondez HELP pour de l’aide ou STOP pour arrêter à tout moment. Nos conditions et notre politique de confidentialité sont sur laawoldigital.com/sms.html. Voulez-vous recevoir votre reçu par message texte, oui ou non ? »

Si vous dites oui, l’employé répond : « Merci. Je l’envoie maintenant ; le texto que vous recevez est votre confirmation. » L’employé appuie sur « Envoyer le reçu » et choisit « Message texte » uniquement si vous dites oui. Si vous dites non, aucun texto n’est envoyé. La même question s’affiche à l’écran de l’employé avant tout envoi. Accepter n’est pas une condition pour expédier un colis : vous pouvez recevoir votre reçu sur papier, par e-mail ou sur WhatsApp.

3. Ce que nous envoyons

Un seul message texte avec un lien vers le reçu de votre colis (le prix, ce que vous avez payé et ce qu’il reste à payer). Par exemple :

Example Shipping LLC: your package receipt CL-K7M4P2 / votre reçu de colis CL-K7M4P2 : https://laawoldigital.com/d?… Reply STOP to opt out, HELP for help.

Nous n’envoyons ni publicité ni promotion par message texte.

4. Fréquence

Un message chaque fois que vous demandez un reçu. Il n’y a pas de messages récurrents ni programmés.

5. Coût

Laawol et l’entreprise d’expédition ne facturent rien pour ces messages. Des frais de messages et de données peuvent s’appliquer selon votre forfait mobile.

6. Comment arrêter et comment obtenir de l’aide

Répondez STOP à n’importe quel message pour arrêter tous les messages texte de ce numéro. Vous recevrez un dernier message de confirmation (en anglais) : « You have successfully been unsubscribed. You will not receive any more messages from this number. Reply START to resubscribe. » Répondez START pour recevoir de nouveau les messages.

Répondez HELP pour de l’aide, ou écrivez à legal@laawoldigital.com. La réponse à HELP est (en anglais) : « Laawol Digital: package receipts by text. Help: legal@laawoldigital.com. Msg & data rates may apply. Reply STOP to stop. »

7. Votre numéro et votre vie privée

Nous utilisons votre numéro de mobile uniquement pour envoyer le message que vous avez demandé. Nous ne vendons pas, ne louons pas et ne partageons pas votre numéro de mobile ni votre accord pour les messages texte avec des tiers ou des sociétés affiliées à des fins de marketing ou de promotion. Consultez notre Politique de confidentialité.

8. Acheminement

Les opérateurs mobiles ne sont pas responsables des messages retardés ou non remis. Si un texto ne vous parvient pas, l’entreprise peut vous montrer le reçu, l’imprimer ou vous l’envoyer par e-mail.
